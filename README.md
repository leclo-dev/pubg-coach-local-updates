# PUBG Coach Local — Windows updates

Windows x64용 개인 PUBG 코칭 프로그램의 설치 파일 배포 저장소입니다.

[최신 설치 파일](https://github.com/leclo-dev/pubg-coach-local-updates/releases/latest)

설치 파일을 실행한 뒤 바탕화면의 PUBG Coach Local을 여세요. 처음 한 번 설치하면 **도구 → 프로그램 업데이트**에서 다음 버전을 받을 수 있습니다. 이미 사용하던 개인 자료 폴더는 유지됩니다.

경기 입력·개인 메모·설정은 `문서\PUBG Coach Local Data\workspace`에 별도로 저장됩니다. 이 저장소와 설치 파일에는 개인 경기 입력이나 메모가 포함되지 않습니다. 새 PC로 개인 자료를 옮기는 작업과 프로그램 업데이트는 별개입니다.

앱을 사용하는 동안 시작 시와 6시간마다 새 버전을 확인합니다. 다운로드와 설치는 사용자가 선택하며, 일반 종료 시 자동 설치하지 않습니다. 대회 자료 자동 갱신은 데이터 관리에서 별도로 설정합니다.

배포물은 개인용 Windows 미서명 빌드입니다. 게시된 SHA-256과 업데이트 메타데이터의 SHA-512는 파일 무결성 확인용이며 Windows 발급자 코드 서명은 아닙니다.

PUBG Corporation/KRAFTON의 공식 제품이 아닙니다. 지도·팀 로고 등 참고 자료의 권리는 각 권리자에게 있습니다. 과거 경기의 차량 생성·맵 빌드나 실제 선수 계정이 검증되었다는 의미가 아닙니다.
